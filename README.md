# АрбузФуд — коммерческое предложение (лендинг)

Статичная страница с КП «Единая B2B платформа для АрбузФуд» от 20 ноября 2026.

- `index.html` — страница входа по паролю. Само КП лежит внутри неё в зашифрованном виде (PBKDF2-SHA256, 300 000 итераций + AES-256-GCM) и расшифровывается в браузере после ввода пароля. Без пароля текст КП из файла не достать.
- `tools/gate.html` — шаблон страницы входа, `tools/protect.mjs` — скрипт шифрования.
- `assets/kazdata-logo.svg` — логотип KazData Solutions в подвале.
- `assets/fonts/` — шрифт Onest (SIL OFL, см. `OFL.txt`), ближайший свободный аналог Gilroy с arbuzfood.kz.

Внешних зависимостей нет: страница работает с любого статического хостинга (nginx, Caddy, GitHub Pages) — достаточно отдать папку целиком.

Страница закрыта от индексации (`<meta name="robots" content="noindex, nofollow">`).

## Как вносить правки

Исходник страницы (`index.src.html`) в репозиторий не коммитится, он в `.gitignore`. Порядок работы (нужен Node 18+):

```bash
node tools/protect.mjs unlock   # спросит пароль и достанет index.src.html из index.html
# ...правим index.src.html...
node tools/protect.mjs lock     # спросит пароль и пересоберёт зашифрованный index.html
git add index.html && git commit -m "..." && git push
```

Пароль можно передать и переменной: `KP_PASSWORD=... node tools/protect.mjs lock`. Чтобы сменить пароль, сделайте `unlock` со старым и `lock` с новым.

## Где править цифры

Данные лежат массивами в конце `index.src.html`:

- `B` — 15 статей бюджета (номер, название, сумма, группа);
- `G` — 6 групп для «арбузного» графика;
- `M` — 14 модулей раздела «Состав работ»;
- `ROWS`, `MONTHS` — график на 4 месяца.

Суммы групп и модулей считаются из `B` автоматически. Если сумма статей разойдётся с 10 800 000 ₸, в консоли браузера появится предупреждение. Итог также указан текстом в первом экране, подвале таблицы и следующих шагах — при смене цены поправьте и его.
